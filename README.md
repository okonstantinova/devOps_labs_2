# Лабораторная работа №4
## Цель лабораторной работы

Освоить методы создания образов с разными уровнями зависимостей

## Реализация

1. Создать Dockerfile, который будет называться system. 
В него будут установлены все зависимости для сборки проекта. Как пример голая node нужной версии.

Создаем `Dockerfile.system`, который только устанавливает Node.js и создаёт пользователя:
<img width="561" alt="Снимок экрана 2025-03-01 в 23 01 30" src="https://github.com/user-attachments/assets/c5d50982-4b8d-4750-897e-222069f81c6b" />

2. Создать Dockerfile Для сборки и назвать его build. 
В нем будет собираться проект, он должен использовать имедж system. 
В build нельзя устанавливать никакие дополнительные зависимости, т.е. apk add, apt install и пр. запрещены. 
В нём можно только скачивать зависимости и делать сборку проекта.

Создаем файл `Dockerfile.build`, который берёт `system` и использует его для установки зависимостей и сборки:
<img width="558" alt="Снимок экрана 2025-03-01 в 23 11 56" src="https://github.com/user-attachments/assets/ad492d75-8386-4db6-93d1-3c400adddcd9" />

3. Создать Dockerfile, который будет запускать код , который собрался в build. 
В нем должен быть только инструмент для запуска вашего проекта, как пример для node проекта - npm run start и пр. 
Если у вас python проект - объединять 2 и 3 шаги - можно. 
Если вы билдите проект на GO - тогда должен быть только бинарник для запуска.

Создаем `Dockerfile.runtime`, который использует `build` и копирует только собранный код:
