# Лабораторная работа №3

## Цель лабораторной
Освоить подход создания легковесного образа путем сборки приложения на одном образе, и запуска на другом. Рекомендуется использовать любое опенсорс приложение требующее сборку приложение (Java,C/C++,Golang, Node).

## Реализация
1. Образ должен быть легковесным

`Alpine` — это минимальный Linux-дистрибутив (~5MB), что делает образ легче

2. Использовать базовые легковестные образы - alpine

В `Dockerfile` в обоих этапах *используется* `node:18-alpine`, который основан на Alpine. Никаких тяжёлых зависимостей (`ubuntu`, `debian`) *не используется*.

Один `Dockerfile`, содержащий оба этапа:

- Этап 2: запуск (*runtime*)
